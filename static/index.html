No Kamus server

This copy runs without the Kamus server (for example as a static website). Everything that works in the browser is available: Wiktionary and Tatoeba lookups, cards, backup, sync, .apkg export, the base-word finder, MyMemory and Opus-MT translation, learning pages and the browser voice. These need the server and are switched off: KBBI, edge-tts, the Wikidepia voices, Argos and LibreTranslate.
